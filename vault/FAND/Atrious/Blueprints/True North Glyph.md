# True North Glyph

*Artifact — [[FAND/Atrious/Professions/Enchanting|Enchanting]] (Glyph Inscription) — Common*

An unusual artifact, inscribed with warded glyphwork using Sealing Wax. Unremarkable to look at, but it does exactly what it's meant to. A common enough commission that most workshops keep the pattern on hand.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Plain Sealing Wax Tablet|Plain Sealing Wax Tablet]], [[FAND/Atrious/Blueprints/Plain Sealing Wax Vessel|Plain Sealing Wax Vessel]]. The difference is form and handling: pick whichever shape suits the wielder.
