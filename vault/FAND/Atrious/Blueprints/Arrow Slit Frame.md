# Arrow Slit Frame

*Artifact — [[FAND/Atrious/Professions/Engineering|Engineering]] (Siege Engineering) — Common*

An iron frame for a defensive arrow slit, 3 inches wide by 18 inches tall. Set into a wall, it provides a firing position that protects the archer completely. The angle of the slit allows firing in a 90-degree arc…

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Caltrop Spreader|Caltrop Spreader]], [[FAND/Atrious/Blueprints/Cauldron Bracket|Cauldron Bracket]], [[FAND/Atrious/Blueprints/Cauldron Over Gate|Cauldron Over Gate]], [[FAND/Atrious/Blueprints/Gate Lock Bar|Gate Lock Bar]]. The difference is form and handling: pick whichever shape suits the wielder.
