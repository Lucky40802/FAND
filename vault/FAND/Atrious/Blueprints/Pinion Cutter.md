# Pinion Cutter

*Artifact — [[FAND/Atrious/Professions/Engineering|Engineering]] (Clockwork Engineering) — Common*

A purpose-built artifact, assembled from precision clockwork parts using Tension Spring. Unremarkable to look at, but it does exactly what it's meant to. A minor variation on a well-worn design.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Dividing Head|Dividing Head]], [[FAND/Atrious/Blueprints/Journeyman's Tension Spring Automaton|Journeyman's Tension Spring Automaton]].
