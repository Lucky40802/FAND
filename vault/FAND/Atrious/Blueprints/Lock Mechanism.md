# Lock Mechanism

*Artifact — [[FAND/Atrious/Professions/Engineering|Engineering]] (Clockwork Engineering) — Common*

A basic pin-tumbler lock. Four pins, key-cut to a simple bitting. Provides minimal security. The first project of any clockwork engineer.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Pocket Watch|Pocket Watch]], [[FAND/Atrious/Blueprints/Spring Latch|Spring Latch]]. The difference is form and handling: pick whichever shape suits the wielder.
