# Shamshir

*Artifact — [[FAND/Atrious/Professions/Blacksmithing|Blacksmithing]] — Uncommon*

The Persian predecessor of the sabre. An extremely curved, narrow-bladed sword with almost no point — the curve is so pronounced that thrusting is essentially impossible. Designed entirely for the draw-cut on horseback.
