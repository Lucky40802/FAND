# Unbreakable Glyph

*Artifact — [[FAND/Atrious/Professions/Enchanting|Enchanting]] (Glyph Inscription) — Common*

Applied to any non-magical object. The object cannot be broken by any mundane means.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Object Strength Glyph|Object Strength Glyph]], [[FAND/Atrious/Blueprints/Strength Glyph - Object|Strength Glyph - Object]]. The difference is form and handling: pick whichever shape suits the wielder.
