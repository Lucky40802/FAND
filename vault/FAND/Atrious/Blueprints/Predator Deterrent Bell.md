# Predator Deterrent Bell

*Artifact — [[FAND/Atrious/Professions/Harvesting|Harvesting]] (Beast Taming) — Common*

A specialized artifact, shaped for handling and bonding with beasts using Bonding Sigil Ink. Solid, dependable work — nothing about it is flashy, but it holds up. The finish differs from smith to smith, though the core work is identical.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Journeyman's Bonding Sigil Ink Collar|Journeyman's Bonding Sigil Ink Collar]]. The difference is form and handling: pick whichever shape suits the wielder.
