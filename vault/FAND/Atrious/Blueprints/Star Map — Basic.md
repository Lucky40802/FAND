# Star Map — Basic

*Artifact — [[FAND/Atrious/Professions/Navigation|Navigation]] (Astral Navigation) — Common*

A star map on vellum showing the constellations visible from the current latitude. Used for celestial navigation. Accurate but not magical — it shows what should be there, not what is there when clouds intervene.
