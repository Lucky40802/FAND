# Mechanical Caltrops Deployer

*Artifact — [[FAND/Atrious/Professions/Engineering|Engineering]] (Clockwork Engineering) — Common*

A box containing 20 steel caltrops and a spring mechanism. When the release is pulled, the caltrops scatter in a 10ft radius from the box. Can be set to deploy by pressure plate or remote cord pull. A faster deployment…

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Clockwork Trap — Spring|Clockwork Trap — Spring]], [[FAND/Atrious/Blueprints/Clockwork Turnspit|Clockwork Turnspit]]. The difference is form and handling: pick whichever shape suits the wielder.
