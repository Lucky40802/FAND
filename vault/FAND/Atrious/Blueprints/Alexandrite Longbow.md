# Alexandrite Longbow

*Bow — [[FAND/Atrious/Professions/Carving|Carving]] (Crystal Shaping) — Very Rare*

A 6-foot bow. The Alexandrite stave is unpredictable — the damage type changes randomly with each strike.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Alexandrite Crossbow|Alexandrite Crossbow]], [[FAND/Atrious/Blueprints/Alexandrite Shortbow|Alexandrite Shortbow]]. The difference is form and handling: pick whichever shape suits the wielder.

## Material Property
**Spell Vessel** (Potency 1, from Alexandrite): Stores one spell of level 1 or lower, recast once per long rest. Focus: +1 to spell attacks.

See [[FAND/Atrious/Material Properties|Material Properties]].
