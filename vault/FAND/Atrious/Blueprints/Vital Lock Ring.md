# Vital Lock Ring

*Artifact — [[FAND/Atrious/Professions/Alchemy (Profession)|Alchemy]] (Blood Alchemy) — Common*

A ring that detects the wearer's vitals. If the wearer drops below 25% HP, the ring sends a blood-pulse message to a linked ring within 1 mile.
