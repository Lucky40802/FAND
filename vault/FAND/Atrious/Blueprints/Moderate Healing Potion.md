# Moderate Healing Potion

*Potion — [[FAND/Atrious/Professions/Alchemy (Profession)|Alchemy]] (Potionmaking) — Uncommon*

An improved healing potion using more concentrated reagents. Restores 4d4+4 HP on consumption. More expensive than the basic version but provides meaningfully better recovery. Worth carrying for serious wounds.
