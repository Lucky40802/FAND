# Soul Eater Greatsword

*Sword — [[FAND/Atrious/Professions/Enchanting|Enchanting]] (Soul Binding) — Very Rare*

A greatsword of soulsteel set with necromancy stones. Each kill stores the soul in the blade. The wielder can expend stored souls for +1d8 necrotic damage per soul on a single attack.

## Material Property
**Tempered** (Potency 1, from Soulsteel): Weapon: +1 damage. Armor: +1 Gear AC.
