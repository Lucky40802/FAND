# Master Runesmith's Chisel Set

*Artifact — [[FAND/Atrious/Professions/Enchanting|Enchanting]] (Sigilcraft) — Uncommon*

A set of nine chisels with runesteel tips. Each chisel is attuned to a different runic family. Using this set, the runesmith reduces the time to inscribe any rune by half and gains +2 to all Sigilcraft checks.
