# Saddle — Basic

*Artifact — [[FAND/Atrious/Professions/Harvesting|Harvesting]] (Beast Taming) — Common*

A basic riding saddle for a Large quadruped. The tree is carved wood; the seat and panels are padded leather. Stirrups are included. Properly fitted, provides a stable seat for 8 hours of riding without sores.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Beast Treat - Carnivore|Beast Treat - Carnivore]], [[FAND/Atrious/Blueprints/Beast Wound Wrap|Beast Wound Wrap]], [[FAND/Atrious/Blueprints/Riding Saddle - Horse|Riding Saddle - Horse]], [[FAND/Atrious/Blueprints/Saddlebags — Large|Saddlebags — Large]]. The difference is form and handling: pick whichever shape suits the wielder.
