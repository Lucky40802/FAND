# Runecarving Tools

*Artifact — [[FAND/Atrious/Professions/Enchanting|Enchanting]] (Sigilcraft) — Uncommon*

A set of hardened steel chisels, gouges, and scribes for carving runes into stone, metal, and bone. The tips are diamond-coated for working hard materials. Includes a reference pamphlet of basic rune forms.
