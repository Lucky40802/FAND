# Blood Sight Potion

*Artifact — [[FAND/Atrious/Professions/Alchemy (Profession)|Alchemy]] (Blood Alchemy) — Uncommon*

Drinking this potion allows the user to track any living creature whose blood they have tasted within the last week. Range: 5 miles.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Blood Sight Helm|Blood Sight Helm]]. The difference is form and handling: pick whichever shape suits the wielder.
