# Sturdy Comet Dust Compass

*Artifact — [[FAND/Atrious/Professions/Navigation|Navigation]] (Astral Navigation) — Uncommon*

A sturdy compass built from comet dust, taught early in Astral Navigation training. Reliable, unremarkable, and easy to reproduce.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Feywild Approach Guide|Feywild Approach Guide]], [[FAND/Atrious/Blueprints/Shadow Approach Guide|Shadow Approach Guide]].
