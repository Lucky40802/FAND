# Haemostatic Powder

*Artifact — [[FAND/Atrious/Professions/Alchemy (Profession)|Alchemy]] (Blood Alchemy) — Common*

Stops bleeding immediately. Creatures cease taking bleed damage when this is applied.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Blood Test Kit|Blood Test Kit]]. The difference is form and handling: pick whichever shape suits the wielder.
