# Common Sealing Wax Tablet

*Artifact — [[FAND/Atrious/Professions/Enchanting|Enchanting]] (Glyph Inscription) — Common*

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Common Sealing Wax Vessel|Common Sealing Wax Vessel]]. The difference is form and handling: pick whichever shape suits the wielder.
