# File

*Artifact — [[FAND/Atrious/Professions/Blacksmithing|Blacksmithing]] — Common*

A flat file with cross-cut teeth. Used to finish metal surfaces after forging. The teeth are cut by hand with a chisel.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Draw Knife|Draw Knife]], [[FAND/Atrious/Blueprints/Farrier's Rasp|Farrier's Rasp]], [[FAND/Atrious/Blueprints/Steel Saw|Steel Saw]], [[FAND/Atrious/Blueprints/Steel Scissors|Steel Scissors]]. The difference is form and handling: pick whichever shape suits the wielder.
