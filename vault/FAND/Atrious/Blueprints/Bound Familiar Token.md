# Bound Familiar Token

*Artifact — [[FAND/Atrious/Professions/Enchanting|Enchanting]] (Soul Binding) — Common*

A small carved token through which a mage's familiar can communicate telepathically with the mage regardless of distance, as long as both are on the same plane. The token holds the familiar's soul-bond.
