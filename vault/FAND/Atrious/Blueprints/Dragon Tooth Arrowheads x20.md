# Dragon Tooth Arrowheads x20

*Bow — [[FAND/Atrious/Professions/Carving|Carving]] (Dragon Carving) — Uncommon*

Twenty arrowheads shaped from dragon teeth. Each tooth is shaped to a broadhead profile. The teeth carry elemental affinity — fire-dragon teeth leave burning wounds, ice-dragon teeth chill. The effect fades on impact. …
