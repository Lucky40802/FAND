# Common Fragment of the Original Relic

*Artifact — [[FAND/Atrious/Professions/Enchanting|Enchanting]] (Relic Restoration) — Uncommon*

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Enchantment Reconstruction Frame|Enchantment Reconstruction Frame]], [[FAND/Atrious/Blueprints/Material Composition Analyser|Material Composition Analyser]].
