# Scale Armour Insert

*Armor — [[FAND/Atrious/Professions/Carving|Carving]] (Dragon Carving) — Common*

Dragon scales fitted as a chest insert to any existing armour. The scale insert provides resistance to the elemental damage type of the source dragon — fire from a red, cold from a white, lightning from a blue, etc.…
