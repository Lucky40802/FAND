# Prismaite Rune-Bound Charm x1

*Artifact — [[FAND/Atrious/Professions/Enchanting|Enchanting]] (Sigilcraft) — Very Rare*

A rune-bound charm incorporating Prismaite (Gemstone & Crystal). A crystal that cycles through all colours constantly. The damage type changes with the colour — fire when red, cold when blue, lightning when yellow, etc. Roll 1d6 on each hit: 1=Fire, 2=Cold, 3=Lightning, 4=Acid, 5=Force, 6=Radiant. Cannot predict or control the type. Bonus: Random elemental on each hit.
