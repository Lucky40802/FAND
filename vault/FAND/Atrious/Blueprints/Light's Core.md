# Light's Core

*Artifact — [[FAND/Atrious/Professions/Enchanting|Enchanting]] (Elemental Binding) — Legendary*

This core only functions at its full power because it channels a fragment of [[Light]] directly, bound into a core of Alexandrite (+1d4 random). Reserved for those who hold a genuine Primary connection to that Law, per the [[Class]] acquisition system. No substitute relic or lesser link will do.
