# Traverse Board

*Artifact — [[FAND/Atrious/Professions/Navigation|Navigation]] (Astral Navigation) — Common*

A specialized artifact, built for reading the stars and the space between them using Comet Dust. Built to be used, not admired. The finish differs from smith to smith, though the core work is identical.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Basic Comet Dust Compass|Basic Comet Dust Compass]]. The difference is form and handling: pick whichever shape suits the wielder.
