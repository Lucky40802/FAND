# Dragon Egg Shell Fetish x1

*Artifact — [[FAND/Atrious/Professions/Carving|Carving]] (Bone Carving) — Very Rare*

A fetish incorporating Dragon Egg Shell (Dragon Material). The shell of a hatched dragon egg. Empty shells are sometimes gifted by dragon parents. Items made from dragon egg shell grant the bearer +1 to saves against dragon abilities — breath weapons, frightful presence, and so on. Bonus: +1 to dragon-type saves.
