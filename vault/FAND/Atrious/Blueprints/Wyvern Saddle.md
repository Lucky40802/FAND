# Wyvern Saddle

*Artifact — [[FAND/Atrious/Professions/Harvesting|Harvesting]] (Beast Taming) — Uncommon*

A saddle designed for riding a wyvern. The wyvern's back is not ideal for a rider — this saddle corrects for that with a forward-mounted seat and extended safety straps. The dragonscale padding provides fire resistance.
