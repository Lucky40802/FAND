# Sloth's Tablet

*Artifact — [[FAND/Atrious/Professions/Enchanting|Enchanting]] (Glyph Inscription) — Legendary*

This tablet only functions at its full power because it channels a fragment of [[Sloth]] directly, bound into a core of Transmutation Flux (+2, weapon changes damage type each round cycling through all types). Reserved for those who hold a genuine Primary connection to that Law, per the [[Class]] acquisition system. No substitute relic or lesser link will do.
