# The First Key

*Sword — [[FAND/Atrious/Professions/Enchanting|Enchanting]] (Soul Binding) — Very Rare*

The most basic of the Warden Keys — and yet, by every account, not basic at all. A simple key-shaped blade that chose an unlikely wielder over every trained hand that reached for it first. It unlocks the hearts of worlds and can be turned the other way to seal them shut.
