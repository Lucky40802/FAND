# Beast Collar - Basic

*Artifact — [[FAND/Atrious/Professions/Harvesting|Harvesting]] (Beast Taming) — Common*

A leather collar for a small beast. Prevents magical shapeshifting back to humanoid form — useful for keeping shapeshifters contained.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Beast Taming Collar — Small|Beast Taming Collar — Small]], [[FAND/Atrious/Blueprints/Calming Herb Bundle|Calming Herb Bundle]], [[FAND/Atrious/Blueprints/Training Treat — Basic|Training Treat — Basic]]. The difference is form and handling: pick whichever shape suits the wielder.
