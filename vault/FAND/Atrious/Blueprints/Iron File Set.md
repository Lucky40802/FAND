# Iron File Set

*Artifact — [[FAND/Atrious/Professions/Blacksmithing|Blacksmithing]] — Common*

Eight iron files: flat, half-round, round, triangular, knife, needle, and two bastard cuts. Used for shaping metal, sharpening tools, and removing burrs. The teeth are cut by hand into hardened steel.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Hammer Head|Hammer Head]], [[FAND/Atrious/Blueprints/Iron Cauldron|Iron Cauldron]], [[FAND/Atrious/Blueprints/Iron Cooking Grate|Iron Cooking Grate]], [[FAND/Atrious/Blueprints/Iron Crowbar|Iron Crowbar]], [[FAND/Atrious/Blueprints/Tongs|Tongs]]. The difference is form and handling: pick whichever shape suits the wielder.
