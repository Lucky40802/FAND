# Iron Horseshoe Set

*Artifact — [[FAND/Atrious/Professions/Blacksmithing|Blacksmithing]] — Common*

Four iron horseshoes, nails included. Each shoe is hot-fitted in the forge to a standard draft horse size. Proper shoeing prevents lameness. Improper shoeing prevents the blacksmith from being paid.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Iron Belt Buckle|Iron Belt Buckle]], [[FAND/Atrious/Blueprints/Iron Door Hinge|Iron Door Hinge]], [[FAND/Atrious/Blueprints/Iron Fire Poker|Iron Fire Poker]], [[FAND/Atrious/Blueprints/Pot Hook|Pot Hook]], [[FAND/Atrious/Blueprints/Tallow Candle Holder|Tallow Candle Holder]]. The difference is form and handling: pick whichever shape suits the wielder.
