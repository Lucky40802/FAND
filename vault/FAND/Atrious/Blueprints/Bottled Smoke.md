# Bottled Smoke

*Potion — [[FAND/Atrious/Professions/Alchemy (Profession)|Alchemy]] (Blood Alchemy) — Common*

A small ceramic sphere filled with a compressed smoke compound. Smash on any hard surface. Produces a 15ft cloud of thick grey smoke that lingers for one minute in still air. Useful for escapes.
