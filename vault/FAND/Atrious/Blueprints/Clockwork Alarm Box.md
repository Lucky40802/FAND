# Clockwork Alarm Box

*Artifact — [[FAND/Atrious/Professions/Engineering|Engineering]] (Clockwork Engineering) — Uncommon*

A small clockwork box with a tripwire mechanism. Set it in a doorway or on a chest. If disturbed, a spring-loaded bell strikes six times. Runs for 24 hours on a single winding.
