# Happiness's Core

*Artifact — [[FAND/Atrious/Professions/Enchanting|Enchanting]] (Elemental Binding) — Legendary*

This core only functions at its full power because it channels a fragment of [[Happiness]] directly, bound into a core of Deepstone (+2 Bludgeoning). Reserved for those who hold a genuine Primary connection to that Law, per the [[Class]] acquisition system. No substitute relic or lesser link will do.
