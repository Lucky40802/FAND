# The Ancestor's Hammer

*Hammer — [[FAND/Atrious/Professions/Blacksmithing|Blacksmithing]] — Uncommon*

A warhammer with runes naming every master smith who owned it before the current wielder. The list is long. Each rune adds a fragment of the previous owner's skill — the wielder gains +2 to all crafting checks made…
