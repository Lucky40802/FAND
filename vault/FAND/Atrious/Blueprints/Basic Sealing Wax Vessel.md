# Basic Sealing Wax Vessel

*Artifact — [[FAND/Atrious/Professions/Enchanting|Enchanting]] (Soul Binding) — Common*

A basic vessel built from sealing wax, taught early in Soul Binding training. Reliable, unremarkable, and easy to reproduce.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Basic Sealing Wax Tablet|Basic Sealing Wax Tablet]]. The difference is form and handling: pick whichever shape suits the wielder.
