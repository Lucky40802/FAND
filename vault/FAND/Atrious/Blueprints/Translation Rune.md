# Translation Rune

*Artifact — [[FAND/Atrious/Professions/Enchanting|Enchanting]] (Sigilcraft) — Common*

A rune carved into a flat stone. When held while listening to a language the holder doesn't speak, they understand one word per minute. Slow but useful for learning a language in immersive conditions.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Alarm Glyph|Alarm Glyph]], [[FAND/Atrious/Blueprints/Heat Glyph|Heat Glyph]], [[FAND/Atrious/Blueprints/Silence Glyph|Silence Glyph]], [[FAND/Atrious/Blueprints/Strength Glyph|Strength Glyph]]. The difference is form and handling: pick whichever shape suits the wielder.
