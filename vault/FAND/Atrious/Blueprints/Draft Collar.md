# Draft Collar

*Artifact — [[FAND/Atrious/Professions/Harvesting|Harvesting]] (Beast Taming) — Common*

An unusual artifact, shaped for handling and bonding with beasts using Woven Sinew. Solid, dependable work — nothing about it is flashy, but it holds up. A regional variant exists in most workshops, though the differences are cosmetic.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Plain Woven Sinew Collar|Plain Woven Sinew Collar]]. The difference is form and handling: pick whichever shape suits the wielder.
