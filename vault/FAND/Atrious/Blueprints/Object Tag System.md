# Object Tag System

*Artifact — [[FAND/Atrious/Professions/Enchanting|Enchanting]] (Relic Restoration) — Common*

A system of acid-free tags and ties for labelling objects in storage without damaging them.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Rust Removal Solution|Rust Removal Solution]], [[FAND/Atrious/Blueprints/Surface Cleaning Solution|Surface Cleaning Solution]], [[FAND/Atrious/Blueprints/Vacuum Brush|Vacuum Brush]].
