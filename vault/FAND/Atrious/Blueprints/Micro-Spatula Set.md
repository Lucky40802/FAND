# Micro-Spatula Set

*Artifact — [[FAND/Atrious/Professions/Enchanting|Enchanting]] (Relic Restoration) — Common*

An unusual artifact, restored from a recovered relic fragment using Replacement Inlay. Unremarkable to look at, but it does exactly what it's meant to. Every crafter who makes one adds a small personal touch, though the function never changes.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Magnification Hood|Magnification Hood]], [[FAND/Atrious/Blueprints/Plain Replacement Inlay Relic|Plain Replacement Inlay Relic]]. The difference is form and handling: pick whichever shape suits the wielder.
