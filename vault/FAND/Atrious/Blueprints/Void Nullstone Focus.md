# Void Nullstone Focus

*Artifact — [[FAND/Atrious/Professions/Carving|Carving]] (Crystal Shaping) — Very Rare*

A focus of void nullstone used by void mages. Force spells cast using this focus ignore magical resistance and immunity. The null nature of the stone strips away the magical defences of targets before the spell arrives.
