# Pin Vice

*Artifact — [[FAND/Atrious/Professions/Engineering|Engineering]] (Clockwork Engineering) — Common*

A hand-crafted artifact, assembled from precision clockwork parts using Brass Gear. Built to be used, not admired. Every crafter who makes one adds a small personal touch, though the function never changes.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Jeweller's Loupe|Jeweller's Loupe]], [[FAND/Atrious/Blueprints/Simple Brass Gear Automaton|Simple Brass Gear Automaton]]. The difference is form and handling: pick whichever shape suits the wielder.
