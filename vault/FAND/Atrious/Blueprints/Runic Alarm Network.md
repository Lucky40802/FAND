# Runic Alarm Network

*Artifact — [[FAND/Atrious/Professions/Enchanting|Enchanting]] (Sigilcraft) — Uncommon*

Ten paired rune stones. Each stone is linked to the network. When any stone is touched or disturbed, all others vibrate. Used to coordinate guards, signal warnings, or communicate basic yes/no across a building.
