# Speed Saddle

*Artifact — [[FAND/Atrious/Professions/Harvesting|Harvesting]] (Beast Taming) — Uncommon*

A meticulously assembled artifact, shaped for handling and bonding with beasts using Feral Tooth. Built to be used, not admired. A common enough commission that most workshops keep the pattern on hand.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Novice's Feral Tooth Collar|Novice's Feral Tooth Collar]]. The difference is form and handling: pick whichever shape suits the wielder.
