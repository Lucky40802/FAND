# Alexandrite Mace

*Hammer — [[FAND/Atrious/Professions/Carving|Carving]] (Crystal Shaping) — Very Rare*

A flanged one-handed bludgeon. The Alexandrite flanges is unpredictable — the damage type changes randomly with each strike.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Alexandrite Warhammer|Alexandrite Warhammer]]. The difference is form and handling: pick whichever shape suits the wielder.

## Material Property
**Spell Vessel** (Potency 1, from Alexandrite): Stores one spell of level 1 or lower, recast once per long rest. Focus: +1 to spell attacks.
