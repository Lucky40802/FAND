# Alexandrite Hand Axe

*Axe — [[FAND/Atrious/Professions/Carving|Carving]] (Crystal Shaping) — Very Rare*

A one-handed single-bit axe. The Alexandrite head is unpredictable — the damage type changes randomly with each strike. Can be thrown.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Alexandrite Greataxe|Alexandrite Greataxe]]. The difference is form and handling: pick whichever shape suits the wielder.

## Material Property
**Spell Vessel** (Potency 1, from Alexandrite): Stores one spell of level 1 or lower, recast once per long rest. Focus: +1 to spell attacks.
