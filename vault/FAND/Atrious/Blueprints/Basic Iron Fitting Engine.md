# Basic Iron Fitting Engine

*Artifact — [[FAND/Atrious/Professions/Engineering|Engineering]] (Siege Engineering) — Common*

A basic engine built from iron fitting, taught early in Siege Engineering training. Reliable, unremarkable, and easy to reproduce.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Crowbar - Heavy|Crowbar - Heavy]], [[FAND/Atrious/Blueprints/Sandbag Frame|Sandbag Frame]]. The difference is form and handling: pick whichever shape suits the wielder.
