# Mount Celestia Map

*Artifact — [[FAND/Atrious/Professions/Navigation|Navigation]] (Astral Navigation) — Uncommon*

A specialized artifact, built for reading the stars and the space between them using Comet Dust. Solid, dependable work — nothing about it is flashy, but it holds up. A regional variant exists in most workshops, though the differences are cosmetic.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Apprentice Comet Dust Compass|Apprentice Comet Dust Compass]], [[FAND/Atrious/Blueprints/Elysium Map|Elysium Map]]. The difference is form and handling: pick whichever shape suits the wielder.
