# Rune of Memory

*Artifact — [[FAND/Atrious/Professions/Enchanting|Enchanting]] (Sigilcraft) — Common*

A rune carved into an object that, when touched and focused upon, replays the last significant event that happened in its presence — like a brief vision. Duration of the replay is 30 seconds. Used by investigators.…

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Fear Glyph|Fear Glyph]], [[FAND/Atrious/Blueprints/Float Rune|Float Rune]], [[FAND/Atrious/Blueprints/Holding Glyph|Holding Glyph]], [[FAND/Atrious/Blueprints/Reveal Glyph|Reveal Glyph]], [[FAND/Atrious/Blueprints/Rune of Slow Poison|Rune of Slow Poison]], [[FAND/Atrious/Blueprints/Sharpness Rune|Sharpness Rune]]. The difference is form and handling: pick whichever shape suits the wielder.
