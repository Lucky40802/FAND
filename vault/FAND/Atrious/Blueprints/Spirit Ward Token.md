# Spirit Ward Token

*Artifact — [[FAND/Atrious/Professions/Enchanting|Enchanting]] (Soul Binding) — Common*

A token that prevents spirits and undead from approaching within 10ft of it. Not a repulsion effect — spirits simply choose not to approach. Intelligent undead can resist the aversion with a WIS save DC 12.
