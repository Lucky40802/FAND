# Repair Glyph

*Artifact — [[FAND/Atrious/Professions/Enchanting|Enchanting]] (Glyph Inscription) — Common*

A specialized artifact, inscribed with warded glyphwork using Rune Chalk. Reliable enough to see real use in the field. The finish differs from smith to smith, though the core work is identical.

**Stat variants:** shares exactly the same stats (level, damage, materials) with [[FAND/Atrious/Blueprints/Compass Glyph|Compass Glyph]], [[FAND/Atrious/Blueprints/Echo Glyph|Echo Glyph]], [[FAND/Atrious/Blueprints/Journeyman's Rune Chalk Tablet|Journeyman's Rune Chalk Tablet]]. The difference is form and handling: pick whichever shape suits the wielder.
