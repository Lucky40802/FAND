# Aboleth Membrane Collar x1

*Artifact — [[FAND/Atrious/Professions/Harvesting|Harvesting]] (Beast Taming) — Very Rare*

A collar incorporating Aboleth Membrane (Creature Harvest). The membrane lining an aboleth's body cavity. Items made from aboleth membrane can extract memories — a creature that fails against a weapon made from this material has one surface memory extracted and known to the weapon's bearer. Bonus: Memory extraction.
