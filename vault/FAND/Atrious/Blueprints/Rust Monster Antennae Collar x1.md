# Rust Monster Antennae Collar x1

*Artifact — [[FAND/Atrious/Professions/Harvesting|Harvesting]] (Beast Taming) — Rare*

A collar incorporating Rust Monster Antennae (Creature Harvest). The antennae of a rust monster. Items incorporating rust monster antennae cause non-magical metal items to corrode on contact — any metal object struck must DEX save DC 14 or lose 1d4 points of its maximum durability (weapons get -1, armour gets -1 AC). Bonus: Metal dissolution.
