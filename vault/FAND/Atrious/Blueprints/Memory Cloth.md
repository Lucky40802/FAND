# Memory Cloth

*Artifact — [[FAND/Atrious/Professions/Enchanting|Enchanting]] (Soul Binding) — Common*

Cloth woven from the hair of the deceased. Holding it allows the holder to see the last memory of the person it belonged to once per day.
