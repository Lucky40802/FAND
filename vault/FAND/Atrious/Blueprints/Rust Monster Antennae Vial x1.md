# Rust Monster Antennae Vial x1

*Potion — [[FAND/Atrious/Professions/Alchemy (Profession)|Alchemy]] (Blood Alchemy) — Rare*

A vial incorporating Rust Monster Antennae (Creature Harvest). The antennae of a rust monster. Items incorporating rust monster antennae cause non-magical metal items to corrode on contact — any metal object struck must DEX save DC 14 or lose 1d4 points of its maximum durability (weapons get -1, armour gets -1 AC). Bonus: Metal dissolution.
