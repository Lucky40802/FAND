# Transformed Wrench

*Secondary-tier Transmutation*

A transmutation working that punishes a distracted caster more than the basics ever would. A single target within range must succeed on a Strength saving throw or be pushed 15ft in a direction of the caster's choice, falling Prone if it hits a solid surface. If the movement forces it into a wall or other solid obstacle, it takes 6d6 Bludgeoning damage instead of stopping short. Fewer practitioners bother to learn it, since it demands real focus to cast reliably.
