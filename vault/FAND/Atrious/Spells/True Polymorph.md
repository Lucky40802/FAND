# True Polymorph

*SRD — Transmutation (official) — filed under [[FAND/Atrious/Spells/Transmutation (School)|Transmutation]] in this vault*

You transform a creature into a different creature, or a creature or nonmagical object into a different object, on a failed Wisdom save (unwilling targets only); if concentration is maintained for the full hour, the transformation becomes permanent.

**Save:** Wisdom
