# Withering Cycle

*Cantrip — Chronomancy*

A chronomancy basic that survives in every curriculum precisely because it's so cheap to teach. A single target within range must succeed on a Intelligence saving throw or suffer disadvantage on its next attack roll. Simple enough to cast while distracted, which is usually how it gets used.
