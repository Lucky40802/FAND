# Creation

*SRD — Illusion (official) — filed under [[FAND/Atrious/Spells/Shadow Magic (School)|Shadow Magic]] in this vault*

You pull wisps of shadow material from the Shadowfell to create an object of nonliving matter within a 5-foot cube; the more mundane and durable the material, the longer it persists, potentially becoming permanent.

**At Higher Levels:** maximum size of the created object increases per slot level above 5th
