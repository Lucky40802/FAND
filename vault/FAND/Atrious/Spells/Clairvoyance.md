# Clairvoyance

*SRD — Divination (official) — filed under [[FAND/Atrious/Spells/Divination (School)|Divination]] in this vault*

You create an invisible sensor at a location you're familiar with or can see a token/portal for; you can see or hear (your choice) through the sensor as if you were there.
