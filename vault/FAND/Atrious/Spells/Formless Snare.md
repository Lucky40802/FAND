# Formless Snare

*Tertiary-tier Void Magic*

A middling void magic technique, taught somewhere between the basics and real mastery. The caster fixes on a single target within range. Unless it succeeds on a Intelligence saving throw, it falls Prone. A workhorse rather than a showpiece.
