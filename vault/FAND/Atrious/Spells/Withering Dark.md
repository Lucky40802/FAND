# Withering Dark

*Cantrip — Void Magic*

The kind of void magic working passed between friends rather than taught formally. The caster fixes on a single target within range. Unless it succeeds on a Dexterity saving throw, it has disadvantage on its next attack roll. It never scales, but it never needs to.
