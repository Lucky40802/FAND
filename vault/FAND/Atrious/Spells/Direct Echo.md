# Direct Echo

*Cantrip — Psionics*

A psionics basic that survives in every curriculum precisely because it's so cheap to teach. No damage, no save required — the working reveals invisible creatures or objects within range as a faint outline for 1 round. Simple enough to cast while distracted, which is usually how it gets used.
