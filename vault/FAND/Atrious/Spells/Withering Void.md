# Withering Void

*Cantrip — Void Magic*

A void magic exercise more than a spell, the sort drilled into muscle memory early. A single target within range must succeed on a Intelligence saving throw or suffer disadvantage on its next attack roll. The kind of working nobody remembers learning, only knowing.
