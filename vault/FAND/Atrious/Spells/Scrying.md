# Scrying

*SRD — Divination (official) — filed under [[FAND/Atrious/Spells/Divination (School)|Divination]] in this vault*

You create an invisible sensor near a target creature you name or describe, letting you see and hear it; the target can sense the scrying and negate it with a successful Wisdom save if it's aware such magic exists.

**Save:** Wisdom
