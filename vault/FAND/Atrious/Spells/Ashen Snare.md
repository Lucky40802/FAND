# Ashen Snare

*Cantrip — Necromancy*

A necromancy basic that survives in every curriculum precisely because it's so cheap to teach. The caster fixes on a single target within range. Unless it succeeds on a Constitution saving throw, it can't move more than 5ft on its next turn. Simple enough to cast while distracted, which is usually how it gets used.
