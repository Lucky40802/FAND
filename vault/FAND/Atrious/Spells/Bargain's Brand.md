# Bargain's Brand

*Secondary-tier Infernal*

A more demanding infernal working, taught only once the basics are mastered. The caster marks a single target within range. For the duration, the first attack that lands against the marked target each turn deals an extra 2d6 damage. Not every caster keeps this one ready — it costs more attention than most basics do.
