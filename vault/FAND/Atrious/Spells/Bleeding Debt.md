# Bleeding Debt

*Tertiary-tier Infernal*

An ordinary infernal technique, unremarkable but dependable. The caster marks a single target within range. For the duration, the first attack that lands against the marked target each turn deals an extra 1d6 damage. Common enough to be found in nearly every caster's repertoire.
