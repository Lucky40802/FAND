# Null Float

*Secondary-tier Void Magic*

A void magic working that punishes a distracted caster more than the basics ever would. A willing creature becomes weightless for 4 rounds: it can float, fly at its walking speed, and pass through nonmagical objects. Fewer practitioners bother to learn it, since it demands real focus to cast reliably.
