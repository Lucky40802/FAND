# Deathly Blight

*Cantrip — Necromancy*

Widely regarded as the easiest working in necromancy. A single target within range must succeed on a Constitution saving throw or suffer disadvantage on its next attack roll. Unglamorous, but the sort of thing a caster ends up using constantly.
