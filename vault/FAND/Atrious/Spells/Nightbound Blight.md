# Nightbound Blight

*Cantrip — Shadow Magic*

A shadow magic fundamental, drilled into students before anything else. The caster fixes on a single target within range. Unless it succeeds on a Wisdom saving throw, it has disadvantage on its next attack roll. It never scales, but it never needs to.
