# Focused Echo

*Secondary-tier Psionics*

An intermediate psionics working — not hard to learn, but hard to cast well. No damage, no save required — the working lets the caster see through the eyes of a familiar animal within a mile for 1 minute. Fewer practitioners bother to learn it, since it demands real focus to cast reliably. Some casters add a personal flourish to the casting, though it changes nothing about the effect.
