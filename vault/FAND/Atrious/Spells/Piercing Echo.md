# Piercing Echo

*Secondary-tier Psionics*

A working with real teeth, reserved for psionics casters who've put in the hours. No damage, no save required — the working grants the caster knowledge of the exact distance and direction to a named person or object they've met before. Fewer practitioners bother to learn it, since it demands real focus to cast reliably.
