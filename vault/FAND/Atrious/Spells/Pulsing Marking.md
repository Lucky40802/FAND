# Pulsing Marking

*Secondary-tier Blood Magic*

A blood magic technique that asks more of the caster than the basics do. The caster marks a single target within range. For the duration, the first attack that lands against the marked target each turn deals an extra 2d6 damage. Not something a caster reaches for casually.
