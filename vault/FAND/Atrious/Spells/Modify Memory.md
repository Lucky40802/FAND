# Modify Memory

*SRD — Enchantment (official) — filed under [[FAND/Atrious/Spells/Enchantment (School)|Enchantment]] in this vault*

You attempt to reshape a charmed creature's memory of an event from the last 24 hours on a failed Wisdom save, eliminating, changing, or planting a memory of an event that never happened.

**Save:** Wisdom
