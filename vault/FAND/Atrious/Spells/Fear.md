# Fear

*SRD — Illusion (official) — filed under [[FAND/Atrious/Spells/Illusion (School)|Illusion]] in this vault*

You project a phantasmal image of a creature's worst fears; each creature in the cone must drop what it's holding and become frightened for the duration on a failed Wisdom save, using its action to flee by the safest route each turn.

**Save:** Wisdom
