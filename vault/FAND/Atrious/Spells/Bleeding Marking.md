# Bleeding Marking

*Tertiary-tier Blood Magic*

A workaday blood magic technique, the sort taught by rote rather than insight. The caster marks a single target within range. For the duration, the first attack that lands against the marked target each turn deals an extra 1d6 damage. Nothing about the working is subtle, but it does its job.
