# Cold Marking

*Tertiary-tier Necromancy*

An ordinary necromancy technique, unremarkable but dependable. The caster marks a single target within range. For the duration, the first attack that lands against the marked target each turn deals an extra 1d6 damage. A workhorse rather than a showpiece.
