# Bleeding Torment

*Tertiary-tier Infernal*

One of the more forgettable entries in infernal, but a reliable one. The caster marks a single target within range. For the duration, the first attack that lands against the marked target each turn deals an extra 1d6 damage. Nothing about the working is subtle, but it does its job.
