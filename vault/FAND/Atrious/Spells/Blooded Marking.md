# Blooded Marking

*Cantrip — Blood Magic*

A blood magic exercise more than a spell, the sort drilled into muscle memory early. The caster marks a single target within range. For the duration, the first attack that lands against the marked target each turn deals an extra 1d4 damage. The kind of working nobody remembers learning, only knowing.
