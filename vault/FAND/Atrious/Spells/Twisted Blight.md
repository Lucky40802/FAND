# Twisted Blight

*Cantrip — Infernal*

A infernal basic that survives in every curriculum precisely because it's so cheap to teach. A single target within range must succeed on a Constitution saving throw or suffer disadvantage on its next attack roll. Simple enough to cast while distracted, which is usually how it gets used.
