# FAND

The centerpiece of this vault. Everything else — the Rune magic system, the Atrious character-build content, and the visual database app — is part of one campaign world under this name. "Archive of the Lost" was the original standalone name of the imported Atrious material (and its app) before it was merged in; this note replaces it as the hub everything links back to.

## The Rune System
- [[Runes]] — the ~430 Laws that make up this world's magic
- [[Class]] — how a mortal acquires a Class tied to a Rune (Primary/Secondary/Tertiary)
- [[Necromancy]] / [[Undead Summoning]] — the necromancy subsystem
- [[Character Death]] — the baseline death/revival rule
- [[FAND/Atrious/God Contracts|God Contracts]]: ten ranks of service to a god, from Minor up to 1st Finger
- [[FAND/Atrious/God Roster|God Roster]]: all 70 gods with their Runes, realms, contract rewards, Hands, and rivals

- [[FAND/Atrious/Player's Guide|Player's Guide]]: start here. A plain-language tour of FAND's rules for players

- [[FAND/Atrious/Materials/Materials.base|Materials database]]: an Obsidian Base with one note per material, filterable by realm, source, property, and more
- [[FAND/Atrious/Material Properties|Material Properties]]: what each material does in a custom item
- [[FAND/Atrious/Material Refining|Material Refining]]: combine lower-grade materials into higher ones
- [[FAND/Atrious/Realm Travel|Realm Travel]]: reaching other realms, Realm Pressure, and getting home

- [[FAND/Atrious/Monster Stats|Monster Stats]]: homebrew monster stats and converting official stat blocks
- [[FAND/Atrious/Spells/Spell Index|Spells]] — curated, all 20 schools
