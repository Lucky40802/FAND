# FAND Dice Table (physics dice page) - version 2

A standalone page with a real physics engine: grab the dice with your mouse, shake, and throw.

- d2 (coin), d4, d6, d8, d10, d12, d20, d100
- Smooth, weighty mouse throwing with a throw arrow, advantage and disadvantage, modifiers, DC highlighting
- d100 is a true 100-sided die
- Natural 19-20 = critical success, natural 1-2 = critical failure (adjustable)
- Surfaces (felt, wood, ice, grass, rocks), rails on or off (off = open ground, the camera follows your throw), saved maps, gravity / wind / weight sliders
- Dice customiser with streaks, swirls, galaxies and more, saved per die type if you like
- Skip button and instant rolls, a roll log (only clearable in full unless you enter your secret code), streak GIFs
- Share links, an embed mode and a postMessage API (see EMBED_API.md), roll replay, ghost dice, throw styles, bullet-time on crits, atmospheres with ambient sound
- Weather, mood and Fate dice; custom face symbols; 12 fun physics presets with weather, obstacles, tilt and more
- Rules (exploding dice, successes, drop lowest), mini-games, challenge links, QR codes
- Accessibility: colour-blind and high-contrast modes, keyboard/gamepad aiming, one-handed pad, voice throws
- A barebones 10-floor Dice Dungeon in a pop-up (fail a floor and you go back to the start)

## To add it to a site
Give this whole folder to Claude and say: "Add this to my site by following INSTALL_FOR_CLAUDE.md".

The page is the single file `dice-table.html`. You can also just open it by double-clicking it to try it out.
